## Programming Fundamentals (C++) – Lab Tasks

About

This repository contains my lab tasks for the Programming Fundamentals (C++) course. It includes all the practical work and coding exercises completed during the semester.

LAB TASKS folder contains the .cpp source files for all tasks.

Topics Covered

· Basics & Input/Output
· Operators
· Control Structures (if-else, switch, loops)
· Functions
· Arrays
· Strings
· Pointers
· Structures
· File Handling
 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/anfaalrao/Programming Fundamentals.git
   ```
2. Open any .cpp file in your IDE (VS Code, Code::Blocks, Dev-C++).
3. Compile and run
